Dish coverage

Where this list comes from: every extracted recipe's identity card names what it actually is (_identity.likelyDish — free text, written at extraction, with no knowledge of the catalog). A name lands here when it matches nothing the catalog already covers — and "covers" means the dish's name, display name, aliases, and its exact search phrases (accent-folded, word-order-blind, with search dressing like best/easy/recipe ignored). If we are already searching for a phrase, the dish is covered regardless of its title. A searched by note means an existing dish's search phrase loosely contains this name's words — read before creating.

Recipes counts master rows whose identity card names this dish. Tracked traffic is not search volume. dish_keywords holds one row per harvested URL — that URL’s top-ranking keyword and its estimated traffic — across only the ~117 publishers we have run exports for. So this column reads “traffic flowing to pages about this, among the publishers we track”. A dish that is big on sites we have never harvested reads low or zero, and the name match is a substring (Chili catches sweet chili sauce). Treat it as directional ordering, never as a number. Where an existing dish overlaps, the relation says which of three different problems it is, because they want different actions. Split — genuinely different dishes sharing a word (Pasta alla Gricia against alla Norma): create the dish. Variant — the same identity, narrower (Peach Cobbler against Cobbler): a judgement call, not an automatic split, because docs/collections.md §11 is explicit that variants are not the M2M case — you want one winner per identity, since pooling the cohorts mis-grades the minority. Alias — the same dish under another spelling (Coquilles Saint-Jacques / Coquilles Saint Jacques): a synonym, not a dish. This page reports; it never creates — the per-row ➕ dish opens the dish editor with a prefilled New Dish form (this name, two search lines — the name and “name Recipe” — 40 results per line, 15 kept winners, 180-day refresh), which you can adjust before pressing Create. Seasonal dishes read low: a traffic snapshot taken out of season undercounts them.
