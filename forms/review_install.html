Catalog admin

Install Review Grabber

A one-click bookmark that imports the product review you're viewing (its summary + the individual product recommendations) into the review catalog. This is an admin tool. Today it decodes America's Test Kitchen; other sources (Wirecutter, Williams Sonoma, WSJ) are recognized but not yet decodable.

Your device key

This grabber writes review data, so it carries a key identifying the curator. One per device — adding one here never disturbs your other machines.

Checking…

Drag this button onto your bookmarks bar:

Grab Review

Then open a product review page (e.g. an America's Test Kitchen equipment review) and click it.

No bookmarks bar showing?

  1. Chrome / Edge: Ctrl+Shift+B (or ⌘+Shift+B on Mac) to toggle it.
  2. Firefox: right-click the toolbar → Bookmarks Toolbar → Always Show.
  3. Safari (Mac): View menu → Show Favorites Bar.

Can't drag? Paste it as a bookmark URL instead.

Click to copy.

  1. Right-click your bookmarks bar → Add page… (or Ctrl+D, then edit).
  2. Name it Grab Review, paste the copied text as the URL, save.

Catch: if pasting silently strips javascript: off the front (browsers do this for security), put the cursor at the very start of the URL and type those 11 characters back in by hand.

Tap to copy the bookmarklet URL to your clipboard.

  1. Tap the button above to copy.
  2. Bookmark this page: tap Share ⬆️ → Add Bookmark → Save.
  3. Open Bookmarks (the open-book icon) → Edit.
  4. Tap the bookmark you just made. Change the name to Grab Review and replace the URL by pasting (tap-and-hold the URL field → Paste).
  5. Tap Done. You're installed.

Catch: If pasting silently strips javascript: off the front, position the cursor at the start of the URL and type those 11 characters in manually.

Using it

  1. Open a product review page in Safari.
  2. Tap the Grab Review bookmark.
  3. A new tab opens on the Reviews editor with the imported review + its product recs. The original page stays on screen until the import finishes.

First time only: if nothing happens, go to Settings → Safari → Block Pop-ups and turn it OFF (or allow pop-ups for recipes.tbotb.com).
