Save Recipe from any app

A Shortcut that puts Save Recipe in your iPhone's share sheet — Instagram, TikTok, Facebook, YouTube, Safari, anywhere a post can be shared.

Get the shortcut

Opens in Shortcuts. Tap Add Shortcut, then skip to Using it below.

Build it once (about three minutes)

Six actions in the Shortcuts app. Copy the address first — you will paste it in step 4.

…/stage-share

  1. Open Shortcuts and tap +. Tap the name at the top and call it Save Recipe.
  2. Share sheet on. Tap the ⓘ at the bottom, turn on Show in Share Sheet, and close it. A block appears at the top reading Receive Any input from Share Sheet. Tap Any, untick everything except URLs and Safari web pages, tap Done.
  3. Fetch the post. Add the action Get Contents of URL. Tap its URL field and choose the Shortcut Input variable. Leave it as GET.
  4. Hand it to the kitchen. Add Get Contents of URL a second time. Paste the copied address into its URL field. Tap Show More: Method POST, Request Body JSON. Add three fields, all of type Text:
    • key url → value Shortcut Input
    • key html → value Contents of URL (the result of step 3)
    • key via → value shortcut
  5. Read the answer. Add Get Dictionary Value: get Value for key open in Contents of URL (the result of step 4 — pick the second one).
  6. Open it. Add Open URLs and set it to Dictionary Value. Tap Done.

The first time it runs, iOS asks whether Save Recipe may contact this site and the post's site. Choose Always Allow.

Using it

  1. On a post, tap Share (the paper plane on Instagram, the arrow elsewhere) and choose Share to… if the app offers it.
  2. Scroll the list to Save Recipe and tap it.
  3. Safari opens on the import page, then the editable recipe form. Sign in if asked; the recipe saves to whoever signs in.

Ordinary recipe sites open straight into the editor, which fetches the page itself. Instagram, Facebook, TikTok and YouTube posts are read from the caption or description, and from the transcript where there is one. A private post, or one that wants you signed in, comes back with a note saying so — open it in Safari and use the Grab Recipe bookmark, or share a screenshot of the recipe.

Give it to the family

Once yours works: in Shortcuts, tap-and-hold Save Recipe → Share → Copy iCloud Link, and paste that link into System settings under iOS share-sheet Shortcut. This page then shows a one-tap Get the shortcut for everyone else.

Prefer a bookmark in Safari? Install the Grab Recipe bookmarklet.
